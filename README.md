# Rain (Learning Project)

Interactive website simulating rainfall, created as a learning project.

## Purpose
This project was built for educational purposes to practice DOM manipulation, JavaScript animations, and CSS styling.

## Features
- Animated rainfall effect
- Interactive elements with JavaScript
- CSS3 styling
- HTML5 styling

## Tech Stack
- HTML5
- CSS3
- JavaScript
